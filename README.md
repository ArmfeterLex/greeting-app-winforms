# Greeting App WinForms

Простое приложение на C# Windows Forms, которое приветствует пользователя по имени.

<img width="594" height="397" alt="Greeting App WinForms" src="https://github.com/user-attachments/assets/c8c1406a-85c1-4b7b-b08e-4808da4d060a" />

## Функциональность

- Ввод имени в текстовое поле
- Кнопка "Привет" — выводит персонализированное приветствие
- Кнопка "Выход" — закрывает приложение

## Интерфейс

- textBox1 — поле для ввода имени
- button1 — кнопка приветствия
- button2 — кнопка выхода
- label2 — отображение приветствия

## Пример работы

Ввод: "Александр"
Нажатие кнопки → label2 показывает "Привет Александр"

## Куда можно встроить

- В демонстрационные приложения
- В обучающие проекты по C#
- В стартовые формы более крупных приложений
- В примеры обработки событий кнопок

## Требования

- Windows
- .NET Framework / .NET Core с WinForms

## Примечание

Приветствие формируется простой конкатенацией строки "Привет " и введенного текста.
